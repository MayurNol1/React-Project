# Todo Application — React Context API

A simple and intuitive task manager built with React Context API for global state management. Users can add, update, delete, and toggle task completion easily.

## ✨ Features
- 📝 Create, update & delete tasks  
- ✅ Toggle task completion  
- 🌍 Global state with Context API  
- ⚛️ React Hooks for better performance  

## 🛠️ Tech Stack
- React.js  
- Context API  
- React Hooks  

## 🚀 Getting Started
Run the project locally:

```bash
npm install
npm run dev
