# MegaBlog

MegaBlog is a full-stack blogging platform that allows users to create, edit, and delete posts with secure authentication and role-based access. It includes rich-text editing, image uploads, and a responsive user interface designed for a smooth writing experience.

## ✨ Features
- 🔐 Secure authentication & protected routes  
- 📝 Rich-text post editor  
- 🖼️ Image uploads & storage handling  
- 👥 Role-based access control  
- 📱 Fully responsive UI  

## 🛠️ Tech Stack
- React.js  
- Redux Toolkit  
- React Hook Form  
- Tailwind CSS  
- Appwrite (Auth • DB • Storage)
